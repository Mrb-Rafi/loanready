# Third-party components

> Generated by `python -m scripts.licenses` (run by `python tasks.py docs`) from
> `requirements.lock` and the installed package metadata. Do not edit the table by hand.

LoanReady installs exactly the packages pinned in `requirements.lock`. "Direct" marks the
dependencies chosen in PRD/01 §1.2; the rest are their transitive dependencies.

{table}
## Not installed from the lock

| Component | Licence | How it is used |
|---|---|---|
| Tesseract OCR (optional) | Apache-2.0 | Local binary the user installs separately; `OCR_BACKEND=sidecar` (default in tests) needs no OCR at all |
| Ollama runtime (optional) | MIT | Local model server the user installs separately; `LLM_BACKEND=mock` (default) needs no model |
| Microsoft Phi-3 mini (`phi3:mini`, optional) | MIT | Default local model name in `.env.example`; not bundled, pulled by the user through Ollama |
| OpenAI API (optional) | Service terms of OpenAI | Remote model service, opt-in only; no model weights are distributed; C3 bank identifiers and C4 documents never leave the machine |
| PDF fonts | Standard 14 PDF fonts (Helvetica), built into reportlab | Not embedded; no font files are distributed |

## Data

All business data in this repository (Rina's Bakery: transactions, invoices, bills,
receipts, counterparties, the injected test texts) is **synthetic**, generated by our own
scripts (`datagen/`, seed 20261014). Identifiers are reserved fakes: `.test` e-mail
addresses, `+999` phone numbers and `SBX-` bank accounts. The financial products in
`data/products.json` are fictional.
